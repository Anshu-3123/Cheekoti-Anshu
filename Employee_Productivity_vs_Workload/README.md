
# Employee Productivity vs. Workload

## Objective
Analyze working hours, overtime, engagement, absenteeism, and task completion to identify potential workload bottlenecks.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Methodology
1. Generate synthetic employee data.
2. Calculate descriptive statistics and correlations.
3. Visualize working hours, overtime, engagement, and task completion.
4. Compare productivity across overtime groups.
5. Flag potential workload concerns.
6. Recommend operational improvements.

## Dataset
Synthetic data generated for educational purposes.

## Disclaimer
This project identifies illustrative patterns, not proven causal relationships. Productivity should be evaluated with consideration for task complexity, role differences, quality, and employee well-being.
