# Customer Churn & Retention Intelligence

## Objective
Predict customer churn risk and recommend retention strategies.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Methodology
1. Generate sample customer data.
2. Train a Random Forest model.
3. Evaluate model performance.
4. Identify important features.
5. Recommend retention actions.

## Dataset
Synthetic data generated for educational purposes.

## Disclaimer
Results are illustrative and are not based on actual company data.
