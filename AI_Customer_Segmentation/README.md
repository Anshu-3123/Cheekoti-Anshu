
# AI Customer Segmentation

## Objective
Identify meaningful customer groups using purchasing and behavioral data.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Methodology
1. Generate customer behavior data.
2. Standardize the numerical features.
3. Apply K-Means clustering.
4. Evaluate cluster separation.
5. Profile customer segments.
6. Recommend targeted marketing strategies.

## Dataset
Synthetic data created for educational purposes.

## Disclaimer
Segments and recommendations are illustrative. Validate them using real customer data before making business decisions.
