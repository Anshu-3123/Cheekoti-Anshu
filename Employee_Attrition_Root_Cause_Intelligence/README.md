
# Employee Attrition Root-Cause Intelligence

## Objective
Estimate employee attrition risk and examine organizational factors associated with employees leaving.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Methodology
1. Generate synthetic employee data.
2. Explore employee metrics.
3. Train a Random Forest classifier.
4. Evaluate model performance.
5. Analyze feature importance.
6. Generate supportive retention interventions.

## Dataset
Synthetic employee data created for educational purposes.

## Disclaimer
This project is a learning prototype. Its predictions are not validated for real workplace use and must not be used to make employment decisions.
