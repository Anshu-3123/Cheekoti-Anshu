
# Inventory Optimization

## Objective
Analyze inventory levels and recommend replenishment quantities to help reduce stockout risk.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Methodology
1. Generate a sample inventory dataset.
2. Estimate demand during supplier lead time.
3. Calculate safety stock and reorder points.
4. Evaluate inventory coverage and inventory value.
5. Classify inventory status.
6. Calculate suggested replenishment quantities.
7. Visualize inventory status and reorder points.
8. Develop business recommendations.

## Business Value
Inventory analysis can help businesses plan replenishment,
manage stock availability, and monitor inventory investment.

## Dataset Disclaimer
The dataset is synthetic. Demand estimates, safety stock,
and order quantities use illustrative assumptions and should
be validated before real purchasing decisions.
