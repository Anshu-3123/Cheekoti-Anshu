
# Workforce Capacity & Skill Gap Analysis

## Objective
Compare workforce skill supply with project requirements to identify shortages and recommend training, hiring, and employee allocation strategies.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib

## Methodology
1. Create an employee skill matrix.
2. Define project skill requirements.
3. Calculate the number of employees meeting each skill target.
4. Identify shortages and training opportunities.
5. Visualize skill supply versus demand.
6. Recommend workforce planning actions.

## Dataset
Illustrative employee skill ratings and project requirements.

## Disclaimer
This is a simplified workforce planning prototype. Validate skill ratings, employee availability, and project requirements before making staffing decisions.
