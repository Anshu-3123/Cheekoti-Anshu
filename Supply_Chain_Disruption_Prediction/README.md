
# Supply Chain Disruption Prediction

## Objective
Estimate supply chain disruption risk and recommend mitigation actions.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Methodology
1. Generate synthetic supplier and logistics data.
2. Explore disruption patterns.
3. Train a Random Forest classifier.
4. Evaluate model performance.
5. Analyze feature importance.
6. Estimate disruption risk and recommend actions.

## Dataset
Synthetic data generated for educational purposes.

## Disclaimer
This is an educational prototype. Its predictions are not validated against real supply chain events and should not be used as a production risk system without further testing.
